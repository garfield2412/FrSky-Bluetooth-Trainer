Portable Windows x64 preview.

Download the Windows-x64 ZIP, extract it, and run FrSky Bluetooth Trainer.exe. Python and Python packages are bundled.

Install vJoy separately before connecting. Enable device 1 with the required axes and buttons.
https://github.com/BrunnerInnovation/vJoy/releases/tag/v2.2.2.0

Settings are stored in %LOCALAPPDATA%/FrSky Bluetooth Trainer/config.xml. A config.xml beside the EXE is imported on first use. Keep the EXE in its final location if Windows autostart is enabled.

This preview is unsigned. Windows SmartScreen may ask for confirmation.

Before publishing this draft, verify Bluetooth connection, live inputs, vJoy buttons, simulator launch and tray controls on a Windows x64 PC, including a PC without Python installed.
